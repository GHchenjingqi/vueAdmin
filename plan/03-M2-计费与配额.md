## 步骤 4：quotaGuard 中间件

新建 `server/modules/billing/middleware/quotaGuard.ts`：
```ts
// 按 metric 参数化：quotaGuard('users') / quotaGuard('files') / quotaGuard('workflowRuns')
export function quotaGuard(metric: string) {
  return async (req, res, next) => {
    const tenantId = req.user?.tenantId
    if (!tenantId) return res.status(403).json({ code: 403, message: '无租户上下文' })
    const { allowed, used, limit } = await checkQuota(tenantId, metric)
    if (!allowed) {
      return res.status(402).json({
        code: 402,
        message: '已达配额上限',
        data: { metric, used, limit },
      })
    }
    next()
  }
}
```
挂载点（在 `routes/index.ts` 对应路由 `tenantContext` 之后、controller 之前）：
- `POST /users` → `quotaGuard('users')`
- `POST /upload` → `quotaGuard('files')`
- 工作流触发接口 → `quotaGuard('workflowRuns')`
- 开放 API（M5c）→ `quotaGuard('apiCalls')`

成功写入后在 controller 末尾调 `incrUsage(tenantId, metric)`。删除类操作可酌情减计（users/files）。
