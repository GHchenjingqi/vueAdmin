# M1 · 多租户体系

> 前置：M0 已完成。这是商业化地基，照搬现有 `server/utils/dataScope.ts` 的 WHERE 注入模式，全量覆盖所有业务表。

---

## 目标

1. 引入 `Tenant` 模型，所有业务表加 `tenant_id` 列。
2. 请求级隔离：`tenantId` 经 JWT + AsyncLocalStorage 注入，Sequelize 全局 hook 自动追加 `where tenant_id = ?`。
3. 拿不到 `tenantId` 的查询一律返回空集（`where id=-1` 兜底），平台超管显式 `bypass` 才放行。
4. 在线用户/踢下线按租户隔离。

周期：3 周。完成即可"开第二个客户"。

## 步骤 4：AsyncLocalStorage 租户上下文

新建 `server/modules/tenant/context.ts`：
```ts
import { AsyncLocalStorage } from 'node:async_hooks'

export interface TenantContext {
  tenantId: number | null
  bypass?: boolean          // 平台超管跨租户
  userId?: number
}

export const tenantALS = new AsyncLocalStorage<TenantContext>()

export function runInTenant<T>(ctx: TenantContext, fn: () => T): T {
  return tenantALS.run(ctx, fn)
}

export function getTenantContext(): TenantContext | undefined {
  return tenantALS.getStore()
}
```

## 步骤 5：tenantContext 中间件

```ts
import { runInTenant } from '../context.js'
import { NextFunction, Request, Response } from 'express'

// 平台超管路由（/platform/*）跳过租户隔离
export function tenantContext(req: Request, res: Response, next: NextFunction) {
  const ctx = {
    tenantId: req.user?.tenantId ?? null,
    bypass: req.user?.isPlatformAdmin === true,
    userId: req.user?.id,
  }
  runInTenant(ctx, () => next())
}
```

## 步骤 6：Sequelize 全局 tenant scope hook

新建 `server/modules/tenant/hooks/sequelizeTenantScope.ts`，在 `database.ts` 初始化后调用一次：
```ts
import sequelize from '../../../config/database.js'
import { getTenantContext } from '../context.js'
import { Op } from 'sequelize'

export function registerTenantScope() {
  sequelize.addHook('beforeFind', (options: any) => {
    const ctx = getTenantContext()
    if (!ctx) return                       // 非请求上下文（迁移/脚本）不过滤
    if (ctx.bypass) return                 // 平台超管
    const Model = options.model
    if (!Model?.rawAttributes?.tenantId) return  // 无 tenant_id 列的表（如 tenants 本身）

    const constraint = { tenant_id: ctx.tenantId ?? -1 }
    // 合并进 options.where（兼容已有 where）
    options.where = options.where
      ? { [Op.and]: [options.where, constraint] }
      : constraint
  })

  // 写入前兜底：beforeCreate/beforeBulkCreate 若无 tenantId 且非 bypass，填 -1 防漏
  sequelize.addHook('beforeCreate', (instance: any, options: any) => {
    const ctx = getTenantContext()
    if (!ctx || ctx.bypass) return
    if (instance?.constructor?.rawAttributes?.tenantId && instance.tenantId == null) {
      instance.tenantId = ctx.tenantId ?? -1
    }
  })
}
```
> 关键：`ctx.tenantId ?? -1` —— 拿不到租户时填 -1，使查询不命中任何记录，**杜绝"忘加约束=数据泄漏"**。平台超管 `bypass=true` 跳过。

在 `server/bootstrap.ts` 模型加载后、服务监听前调用 `registerTenantScope()`。
