## 1. 用户旅程 8 步（主流程 + 异常 + 验收）

| # | 环节 | 主流程 | 异常场景（必须覆盖） | 验收标准 |
| --- | --- | --- | --- | --- |
| 1 | 浏览首页/集合页 | 分类导航 → 商品卡片（价格由 Price 组件渲染） | 价格服务不可用 → 卡片骨架 + 重试，不显示 0 元 | 移动端首屏含价值主张 + 主 CTA；价格符号随配置 |
| 2 | 商品详情 | 选规格 → 价格/库存/配送承诺/退货摘要联动 | 不可售 SKU：说明原因（下架/无库存/无该币种价格行）而非仅置灰；404：下架商品返回 404 页 | 每个 SKU 可选且价格/库存随之切换 |
| 3 | 加入购物车 | 游客 token 自动建立 → 行内数量/删除 | 库存不足提示上限；失效商品标记并可移除 | 服务端校验 SKU 与数量；token 不可枚举 |
| 4 | 结算-报价 | `POST /checkout/quote` 服务端重算（忽略前端总价） | **币种配置异常**：CONFIG_MISSING/CONFIG_INVALID → 全站价格区显示「暂时无法结算」并阻断下单；`CURRENCY_CHANGED` → 提示购物车已按新币种重建 | 前端传总价被忽略；报价含 currency/过期时间/版本号 |
| 5 | 结算-信息 | 游客/登录下单；地址表单字段级校验 | 地址不在配送范围 → `ADDRESS_NOT_SHIPPABLE` 不可提交；运费/税费失败 → 阻断或明示，不按 0 | 刷新不丢已填信息（草稿暂存） |
| 6 | 支付 | `POST /payments/session` → 跳转收单页 → Webhook 回写 | 服务商不支持该币种 → PROVIDER_CURRENCY_UNSUPPORTED 明确报错；支付失败/超时 → 库存释放、订单关闭、可重试 | 金额/币种取订单快照；重复提交不重复下单（幂等键） |
| 7 | 结果与订单查询 | 结果页由服务端订单状态驱动 | 改 URL 参数无法伪造成功页；处理中轮询超时提示 | 访问需订单 accessToken；越权 404 |
| 8 | 售后 | 订单详情 → 退货申请（政策资格判断） | 超期/不符合条件 → 明确拒绝原因；退款币种=原订单币种 | 政策版本快照；退款独立状态流 |

## 2. 全局异常场景（横切）

| 场景 | 行为 |
| --- | --- |
| 币种配置缺失/非法/服务不可用（C7） | 前台价格区阻断 + 明确文案；`POST /orders`、`/checkout/quote`、`/payments/session` 一律拒绝（`CONFIG_MISSING` / `CONFIG_INVALID`）；**不得默认 USD 继续** |
| 配置缓存（C8） | 60s TTL + 后台保存主动失效；改币种后 ≤60s 前台生效（G1 实测项） |
| 会话/权限 | 顾客 JWT 与 admin 完全隔离；跨顾客访问订单/地址/购物车 → 404（T-10） |
| 缓存隐私 | 购物车/账户/结算响应 `Cache-Control: private, no-store`（T-11） |
