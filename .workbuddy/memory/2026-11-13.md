## 第五轮：上传 SVG 存储型 XSS + 删除接口路径逃逸（提交 `157b948`，推送待网络恢复）

### 确认并修复的 2 条缺陷

1. **P1 上传 SVG 存储型 XSS**（`server/app.ts` + `server/middleware/uploadValidator.ts`）
   - 上传白名单允许 `.svg`（`uploadValidator.ts` ALLOWED.image.extensions），SVG 是 XML 文本格式、可内联 `<script>`；
   - 全局 CSP（`app.ts:46`）`script-src` 含 `'unsafe-inline'`（Vite HMR 所需）→ **不阻止内联脚本**；
     `script-src-attr 'none'` 只挡事件属性，挡不住 `<script>` 块；
   - `express.static` 以 `image/svg+xml` 提供且无 `Content-Disposition`。
   - **实测响应头确证**：`Content-Type: image/svg+xml` + `script-src 'self' 'unsafe-inline' 'unsafe-eval' …` +
     BODY `<svg …><script>alert(document.domain)</script></svg>` → 访问 `/uploads/xxx.svg` 会在**站点源**下
     执行脚本，可窃取 localStorage 中的管理员令牌 → 存储型 XSS。
   - 修复（双保险）：
     - `app.ts`：`/uploads` 静态资源**覆盖 CSP 为 `sandbox; default-src 'none'; …`**（不含 allow-scripts）
       → 文档式渲染时 SVG 进入不透明沙箱、脚本失效；`<img src>` 图片式渲染不受影响；
       对**历史已上传的 SVG 立即生效**，无需清理数据；
     - `uploadValidator.ts`：新增 `assertSvgSafe()`，拒绝含 `<script>` / `on*=` / `<foreignObject>` /
       `<iframe|embed|object>` / `javascript:` 的 SVG（正常 SVG 图标不误伤）。

2. **P2 删除上传文件的目录边界逃逸**（`server/services/uploadService.ts`）
   原 `filePath.startsWith(UPLOAD_DIR)` 是**前缀匹配** → `../uploads-backup/x` 解析后仍以 `uploads` 开头 →
   校验通过，可删除 uploads 同级目录下任意文件。修复：改用 `relative()` 判定（相对路径不得以 `..` 开头、
   不得为绝对路径）。

### 结论：全部安全（证据充分，非缺陷）
- 博客：`blog/[slug].vue:49` 用 `{{ content }}` 插值(自动转义)，JSON-LD 第40行转义 `<`；非 v-html → 无 XSS。

  providerRef↔orderNo 绑定、CAS 认领、provider 切换拒绝、终态保护、币种以订单快照为准。

- 设置写：`/settings/currency`、`/settings/payment-channels/credentials` 均挂 `requireAdmin`。
- 顾客：注册查重(409)+bcrypt；登录 IP+邮箱限流、恒定错误、blocked 拦截；deleteAccount 需当前密码。
- 评价：`authOf(req)` 取认证顾客，`customerId` 非请求体；`verifyPurchase` 按 email+tenantId+spuId 校验。
- 收藏：add/remove/clear/notify 全部按 `req.customer.customerId` 归属。
- 管理端提权：`userService` 内部 `assertCanAssignRoles`(管理员才可改角色;授 admin/platform_admin 需平台级;禁自我提权)、
  `assertCanMutateProtectedUser`(admin 仅平台级)、`isTargetInScope`(数据作用域)；`updateData` 仅解构安全字段。
- 下单价格：createOrder 经 createQuote 服务端重算；params.items 仅 {skuId,qty}，无 price 字段 → 无价格操纵。
- 监控：`evaluateNow` 无输入、纯内存评估(DEFAULT_ALERT_RULES)，无 SSRF/DoS；dashboard 的 runbook 来自服务端常量。
