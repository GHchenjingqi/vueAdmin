- **挂死误判**：此前"预存在 Redis 阻塞器导致 /api 路由卡死"不成立。真实根因是测试时用了错误 URL（缺 `/v1` 前缀）：`app.ts` 以 `app.use('/api/v1', apiRoutes)` 挂载，真实路径为 `/api/v1/auth/login`、`/api/v1/menus`；缺前缀的 `/api/auth/login` 等不匹配任何路由，被 bootstrap 注册的 **Vite HMR 中间件** 接手而挂起（HTTP 000）。用正确 `/api/v1/...` 路径后 captcha→200、menus→401、login→400 均快速返回，admin API 完全健康。
