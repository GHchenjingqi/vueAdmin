# 2026-11-02

## 工作流设计器 Bug 修复：新增节点乱序 + 节点无法删除

文件：`src/views/WorkflowDesigner.vue`（VueFlow 1.48.2，受控模式 `:nodes`/`:edges` + `@nodes-change`/`@edges-change`）。

### 根因
- **乱序**：双击左侧调色板添加节点时 `addNodeByType` 用 `Math.random()` 随机坐标，节点散落 → 画布看起来"乱序"。
- **不能删除**：`removeSelectedNode` 直接手动过滤 `flowNodes`/`flowEdges` 两个 ref 再靠 prop 回写 VueFlow，受控模式双向同步时序不可靠，删除不生效。

### 修复（最小改动）
- `addNodeByType`：改为按现有节点数纵向排布 `x:260, y:60+offset*110`，新增后 `nextTick`+`fitView({padding:0.2})` 自适应，保证新节点可见且整齐。
- `addNode`：用 store 的 `addNodes([node])` 取代 `flowNodes.push`；选中 `findNode(id)` 真实节点（兜底原对象）。
- `removeSelectedNode`：改用 `removeNodes(nodeId, true)`（自动连带删除关联连线，经 `nodes-change`/`edges-change` 同步回 ref）。
- `removeEdgeFromGraph`：改用 `removeEdges(edge.id)`（连线删除同样可靠）。
- 从 `useVueFlow()` 解构 `addNodes/removeNodes/removeEdges/findNode/fitView`；`vue` 导入补 `nextTick`。

验证：`vue-tsc --noEmit` ✅、`eslint --fix` ✅。

## 工作流设计器 UI 细节修复（同日续）：连线无箭头 + 右侧面板输入框不对齐

### 1. 连线无箭头
- 根因：边创建只设 `type: 'smoothstep'`，未设箭头标记。
- 修复：从 `@vue-flow/core` 导入 `MarkerType`，在 `onConnect`（新建连线）与 `loadDesign`（加载连线）两处给边加 `markerEnd: MarkerType.ArrowClosed`；并在本地 `FlowEdge` 接口补 `markerEnd?: string` 字段（否则 TS 报错）。`addEdge` 会保留该自定义属性。

### 2. 右侧编辑面板输入框/标签不对齐
- 根因：`el-form` 的 `label-width="80px"` 对长标签（如「到期前提醒（小时）」）过窄 → 标签换行/溢出到输入框区域，导致输入框看起来被挤压、左右不齐。
- 修复：
  - 节点配置与边配置两处 `el-form` 的 `label-width` 由 80/92px 统一调到 `130px`（容纳最长标签不换行）。
  - 新增 `.node-config-panel :deep(.el-form-item__label) { white-space: nowrap; }` 禁止标签换行。
  - `.section-title` 加 `padding-left: 130px`，使「审批人规则/自动通过/超时/条件配置」等分段标题与输入框列对齐（原在最左与字段标签/输入框错位）。

验证：`vue-tsc --noEmit` ✅、`eslint --fix` ✅。

## 工作流设计器：节点/连线右键删除（同日续）

### 需求
点击节点后鼠标右键可删除节点（顺带也支持连线右键删除）。

### 实现（最小改动）
- VueFlow 事件：`@node-context-menu`、`@edge-context-menu`、`@pane-context-menu`（payload 分别为 `{event, node}`/`{event, edge}`/`MouseEvent`）。
- 新增 `contextMenu` reactive（`visible/x/y/nodeId/edgeId`）与遮罩层 `.ctx-mask`（fixed 全覆盖，点击/右键空白关闭）+ 菜单 `.ctx-menu`（fixed 定位到光标处）。
- `onNodeContextMenu` / `onEdgeContextMenu`：阻止默认浏览器菜单、`preventDefault`，在光标处弹出菜单并记录目标。
- `deleteFromContextMenu`：节点 → `selectedNode = findNode(id)` 后复用 `removeSelectedNode()`（带确认框，自动清理关联连线）；连线 → 复用 `removeEdgeFromGraph(edge)`。
- 在 `onNodeClick`/`onEdgeClick`/`onPaneClick` 内 `hideContextMenu()`，避免菜单残留。
- 文案：新增 `workflow.designer.deleteNode` / `deleteEdge`（zh-CN / en-US 同步）。

验证：`vue-tsc --noEmit` ✅、`eslint --fix` ✅；已提交 `a176d9a`（含前述箭头/对齐/乱序/删除修复）。
